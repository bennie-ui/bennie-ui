## Example

```tsx
<Page title="Page title" subtitle="Subtitle text">
  <PageActions>
    <SomeControl />
  </PageActions>
  <PageContent>
    {/* charts, tables, forms, etc. */}
  </PageContent>
  <PageFooter>
    <SomeControl />
  </PageFooter>
</Page>
```

## Slot components

`Page` accepts a `title` prop and an optional `subtitle`. The `PageActions` slot is extracted and placed in the top-right of the header. All other slots (`PageContent`, `PageFooter`) render in document order below the header.

```tsx
<Page title="Page title">
  <PageActions>
    <button>Action</button>
  </PageActions>
  <PageContent>
    <p>Content here.</p>
  </PageContent>
</Page>
```

## Slots

| Slot | Position | Purpose |
|---|---|---|
| `PageActions` | Header right | Controls like toggles or buttons |
| `PageContent` | Main area | Charts, tables, forms |
| `PageFooter` | Bottom | Secondary controls, pagination |
